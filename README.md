# KOPI — крипто со сдачи

Интерактивный концепт: оплата картой Альфа Банка округляется вверх, сдача сразу переводится в кошелёк WhiteBird и покупает BTC, ETH или USDT.

**Как показать связку:** Альфа → карта ··7781 → «Пополнить» → KOPI → «Подключить» → «Оплатить картой» → «Открыть WhiteBird». В WhiteBird монета уже в кошельке и в истории.

Демо стартует с нуля: на карте 0 BYN, кошелёк пустой. Данные сохраняются только после ваших действий; «Сбросить демо» очищает всё.

Сверху переключатель приложений, ниже телефон, где кликается всё:

- **Альфа Банк** — KOPI внутри банка: виджеты на главной, шаблоны платежей и подписки с календарём списаний, вкладка KOPI с настройками округления, переводы, пополнение, обмен валюты, отделения на карте, кабинет.
- **WhiteBird** — KOPI в криптобирже, в стиле официального приложения: криптофиатный обмен с заявкой и статусом, пополнение/вывод, конвертация, «Мой QR», история с фильтрами и выгрузкой отчёта в CSV, профиль, способы оплаты, светлая и тёмная тема.

Стек: React 18 + Vite. Сервер не нужен — состояние считается в браузере и хранится в `localStorage`. Курсы BTC/ETH и USD/BYN живые: Vercel-функция `api/rates.js` берёт их у Dzengi/CoinGecko и НБРБ.

## Настройки KOPI

- **Округление** до 1, 5 или 10 BYN (с множителем ×1, ×2, ×5).
- **Процент** с выбором потолка 3, 5 или 10%. Шкала прогрессивная и работает как подоходный налог: до 50 BYN — 3%, с части от 50 до 200 BYN — 5%, с части свыше 200 BYN — 10%. Отчисление растёт без скачков на границах. Шкала задана в `KOPI_TIERS`.
- **Копилка с автопокупкой**: отчисления копятся в BYN, и когда набирается 60 BYN (по умолчанию; можно 100 или 200), WhiteBird покупает монету на всю сумму. Меньше 60 BYN нельзя: это минимальное пополнение WhiteBird. Автопокупку можно выключить и покупать кнопкой — тоже от 60 BYN.
- **KOPI Премиум** — отдельный раздел в обоих приложениях. Подключает до 5 близких к общим накоплениям и показывает вклад каждого. Покупки родственников в демо эмулируются кнопкой.

## Быстрый старт

Нужен Node.js 18+.

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # продакшн-сборка в dist/
```

Прямые ссылки на телефоны: `/#/alfa` и `/#/whitebird`.

## Деплой на Vercel

Импортируйте репозиторий: Framework Preset — **Vite**, Build Command `npm run build`, Output Directory `dist` (уже прописано в `vercel.json`). Папка `api/` автоматически становится serverless-функцией.

## Что внутри

```
src/
  App.jsx               переключатель Альфа / WhiteBird, масштабирование телефона
  shared/               форматирование сумм, курсы, хуки, иконки, шторка, тост
  shared/kopi.js        общая связка KOPI: подключение, настройки и операции — их видят оба приложения
  alfa/                 приложение Альфа Банка: model.js (данные и логика), AlfaApp.jsx, alfa.css
  whitebird/            приложение WhiteBird: model.js, WhiteBirdApp.jsx, whitebird.css
api/rates.js            прокси живых курсов
design-export/          исходные HTML-экспорты концепта
```

Операции эмулируются. Ставки, комиссии и реквизиты — демонстрационные.
